The mean can be calculated for the numeric and logical variables, but
not for the character and factor variables.

``` r
as.numeric(pull(dataframe_P2, logical_vector))
as.numeric(pull(dataframe_P2, character_vector))
as.numeric(pull(dataframe_P2, factor_vector))
```

The logical variables are converted to 0(FALSE) and 1(TRUE). The
character variables are converted to NA because values cannot be
interpreted as numbers. The factor variables are converted to integer.
This helps explain the previous calculation of mean, logical vector can
be treated as 0 and 1, but since character and factor variables are not
numeric variables, so they cannot be directly calculated.
